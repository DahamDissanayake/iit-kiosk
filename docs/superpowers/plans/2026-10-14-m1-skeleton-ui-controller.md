# M1: Skeleton, Redesigned UI and Controller Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fake presence and typed questions drive the redesigned EVE-style bot through every engagement state in a portrait browser window, with the state machine fully unit-tested.

**Architecture:** A pure Python controller (events in, commands out, time injected) sits inside a FastAPI app. The app serves the character UI and a WebSocket at `/ws` on port 8765. A runtime feeds the controller events and carries out its commands. In M1, speech output is a fake babble generator and answers come from a canned answerer; M2 replaces both. The UI is vanilla ES modules with no build step.

**Tech Stack:** Python 3.11+, uv, FastAPI, Uvicorn, pytest, ruff; vanilla JavaScript, inline SVG, CSS, Web Audio API.

**Spec:** `docs/superpowers/specs/2026-10-14-mvp-build-design.md` (requirements in `docs/baseline-spec.md`). Later milestones M2 to M6 each get their own plan.

## Global Constraints

- Work on a branch off `dev` named `task/<KEY>-<short-slug>`; commit messages are `<KEY>: short imperative summary`, where `<KEY>` is the SerenEdge task key.
- Never add a `Co-Authored-By` trailer, a "Generated with" line, or any AI or agent attribution to commits, pull requests, code comments or docs.
- Never commit secrets or a `.env` file.
- Dependencies allowed in M1: `fastapi`, `uvicorn[standard]`; dev only: `pytest`, `httpx`, `ruff`. Add nothing else.
- No PyTorch. No Docker. No Node.js build for the character UI.
- English only. Every visible UI string lives in `ui/js/strings.js`.
- UI palette: white studio, glossy white bot, black visor and text, soft white-blue eyes (`#D8F3FF`), red accents only (`#E1251B`).
- UI animates only `transform` and `opacity` (plus SVG attributes for mouth and eyes) and honours `prefers-reduced-motion`.
- Portrait target: 1080 x 1920.
- The WebSocket protocol follows baseline 7.1 plus the additions in the design spec section 2: `stt`, `menu`, `dev`, and `kids` (`{type:"kids", value}`, sent on session reset so the toggle matches the controller).
- Format and lint before each commit: `uv run ruff format . && uv run ruff check --fix .`

## Review Focus

1. **Detector flicker.** A person dropped by the detector for under 1 s during Attentive must not send the bot back to Idle. (Task 2: `test_brief_detection_gap_does_not_drop_attention`)
2. **Audio queue drains between streamed sentences.** The UI may report `speech.ended` before the next sentence's audio arrives; the turn must not end early. (Task 2: `test_queue_drain_between_sentences_does_not_end_turn`)
3. **Late events from a finished encounter.** Answer sentences or `AnswerDone` arriving after the visitor left must not speak to the next visitor. (Task 2: `test_late_answer_after_visitor_left_is_ignored`)
4. **Echo while speaking.** A transcript that arrives while the bot is talking (its own voice picked up) must be ignored. (Task 2: `test_speech_heard_while_bot_talks_is_ignored`)
5. **TTS failure.** If speech synthesis throws, the conversation must still move on instead of waiting forever for `speech.ended`. (Task 3: `test_tts_failure_does_not_stall_conversation`)

```python
"""Events the controller receives and commands it returns."""

from dataclasses import dataclass, field

# ---- events ----


@dataclass(frozen=True)
class Presence:
    """Snapshot from vision. cx, cy are the target's box centre in -1..1."""

    count: int
    approaching: bool = False
    cx: float = 0.0
    cy: float = 0.0


@dataclass(frozen=True)
class SpeechFinal:
    text: str


@dataclass(frozen=True)
class SpeechEnded:
    """The UI finished playing every queued audio chunk up to and including `id`."""

    id: str


@dataclass(frozen=True)
class AnswerSentence:
    text: str


@dataclass(frozen=True)
class AnswerDone:
    pass


@dataclass(frozen=True)
class AnswerFailed:
    kind: str  # "unmatched" or "offline"


@dataclass(frozen=True)
class Touch:
    event: str  # "talk", "stop", "kids", "menu_item"
    value: object = None


@dataclass(frozen=True)
class CameraStatus:
    ok: bool


@dataclass(frozen=True)
class Tick:
    pass


Event = (
    Presence
    | SpeechFinal
    | SpeechEnded
    | AnswerSentence
    | AnswerDone
    | AnswerFailed
    | Touch
    | CameraStatus
    | Tick
)

# ---- commands ----


@dataclass(frozen=True)
class UiSend:
    msg: dict = field(default_factory=dict)


@dataclass(frozen=True)
class Speak:
    id: str
    text: str


@dataclass(frozen=True)
class StopSpeech:
    pass


@dataclass(frozen=True)
class MicMute:
    muted: bool


@dataclass(frozen=True)
class VisionRate:
    fps: float


@dataclass(frozen=True)
class Ask:
    question: str
    history: tuple[tuple[str, str], ...]
    kids: bool


@dataclass(frozen=True)
class CancelAnswer:
    pass


@dataclass(frozen=True)
class Record:
    type: str
    value: float | None = None


Command = UiSend | Speak | StopSpeech | MicMute | VisionRate | Ask | CancelAnswer | Record
```

```python
"""Fixed spoken lines and the touch-menu answers.

The menu answers are placeholders until IIT supplies approved content; M2 moves them
into the knowledge base as `menu` sources.
"""

import re
from dataclasses import dataclass


@dataclass(frozen=True)
class MenuItem:
    id: str
    label: str
    answer: str


@dataclass(frozen=True)
class Phrases:
    greet: str
    group_greet: str
    kids_greet: str
    followup: str
    bye: str
    unmatched: str
    offline: str
    menu: tuple[MenuItem, ...]


PHRASES = Phrases(
    greet=(
        "Hi! Welcome to IIT. I'm your digital assistant. Ask me about our courses, "
        "the campus, or how LeapGen helps turn ideas into startups."
    ),
    group_greet=(
        "Hello everyone! Welcome to IIT. Ask me anything about our courses, campus or LeapGen."
    ),
    kids_greet=(
        "Hi there, young innovator! Have you ever had an idea to make something better? "
        "Ask me anything about IIT!"
    ),
    followup="Feel free to ask me anything whenever you're ready.",
    bye="Thank you for stopping by. Have a wonderful day!",
    unmatched="Sorry, I don't have that information. You can pick a question on the screen.",
    offline="I can't reach my answers right now. Please pick a question on the screen.",
    menu=(
        MenuItem("programmes", "What can I study at IIT?", "Placeholder answer about programmes."),
        MenuItem("campus", "Where is the campus?", "Placeholder answer about the campus."),
        MenuItem("leapgen", "What is LeapGen?", "Placeholder answer about LeapGen."),
        MenuItem("events", "What's on today?", "Placeholder answer about today's events."),
    ),
)

DECLINES = (
    "bye",
    "goodbye",
    "good bye",
    "no thanks",
    "no thank you",
    "that's all",
    "that is all",
    "nothing else",
    "i'm done",
    "i am done",
    "see you",
)


def is_decline(text: str) -> bool:
    """True for short goodbyes like "No thanks, bye!"; long questions never count."""
    words = re.sub(r"[^a-z' ]", " ", text.lower()).split()
    if not words or len(words) > 6:
        return False
    joined = f" {' '.join(words)} "
    return any(f" {d} " in joined for d in DECLINES)
```

```python
import pytest

from core.controller.machine import Controller, ControllerConfig
from core.controller.phrases import PHRASES, is_decline
from core.controller.types import (
    AnswerDone,
    AnswerFailed,
    AnswerSentence,
    Ask,
    CameraStatus,
    CancelAnswer,
    MicMute,
    Presence,
    Record,
    Speak,
    SpeechEnded,
    SpeechFinal,
    StopSpeech,
    Tick,
    Touch,
    UiSend,
    VisionRate,
)

APPROACH = Presence(1, approaching=True)


class Sim:
    """Drives a Controller with explicit timestamps and keeps every command it returned."""

    def __init__(self, **overrides):
        self.c = Controller(ControllerConfig(**overrides))
        self.out = []
        self.log = []

    def at(self, t, event=None):
        self.out = self.c.handle(event or Tick(), t)
        self.log += self.out
        return self.out

    def end_speech(self, t):
        return self.at(t, SpeechEnded(self.c.pending[-1]))

    def all(self, kind):
        return [c for c in self.log if isinstance(c, kind)]

    def spoken(self):
        return [c.text for c in self.all(Speak)]

    def ui(self, type_, out=None):
        cmds = self.log if out is None else out
        return [c.msg for c in cmds if isinstance(c, UiSend) and c.msg["type"] == type_]

    def to_listening(self):
        self.at(1.0, APPROACH)
        self.end_speech(4.0)
        assert self.c.state == "listening"

    def ask(self, t, question):
        self.at(t, SpeechFinal(question))
        assert self.c.state == "thinking"


# ---- presence and greeting ----


def test_person_entering_zone_makes_bot_attentive_without_speaking():
    s = Sim()
    s.at(1.0, Presence(1))
    assert s.c.state == "attentive"
    assert s.spoken() == []
    assert Record("encounter") in s.out


def test_passer_by_is_not_greeted():
    s = Sim()
    s.at(1.0, Presence(1, cx=-0.8))
    s.at(1.5, Presence(0))
    s.at(2.6)
    assert s.c.state == "idle"
    assert s.spoken() == []


def test_brief_detection_gap_does_not_drop_attention():
    s = Sim()
    s.at(1.0, Presence(1))
    s.at(1.2, Presence(0))
    s.at(1.6, Presence(1))
    assert s.c.state == "attentive"
    assert {"type": "state", "state": "idle"} not in s.ui("state")


def test_approach_greets_once_per_encounter():
    s = Sim()
    s.at(1.0, APPROACH)
    assert s.c.state == "greeting"
    s.at(1.5, APPROACH)
    s.end_speech(4.0)
    s.at(5.0, APPROACH)
    assert s.spoken() == [PHRASES.greet]

    s = Sim()

    assert s.c.state == "attentive"

def test_group_gets_group_greeting():
    s = Sim()
    s.at(1.0, Presence(2, approaching=True))
    assert s.spoken() == [PHRASES.group_greet]


def test_kids_mode_uses_kids_greeting_and_kids_answers():
```

```python
"""Engagement state machine (baseline spec 4.1).

Pure: events in, commands out, time injected. No I/O, so every timing rule is testable.
"""

from __future__ import annotations

import itertools
from dataclasses import dataclass

from core.controller.phrases import PHRASES, Phrases, is_decline
from core.controller.types import (
    AnswerDone,
    AnswerFailed,
    AnswerSentence,
    Ask,
    CameraStatus,
    CancelAnswer,
    Command,
    Event,
    MicMute,
    Presence,
    Record,
    Speak,
    SpeechEnded,
    SpeechFinal,
    StopSpeech,
    Tick,
    Touch,
    UiSend,
    VisionRate,
)

ENGAGED = frozenset({"greeting", "listening", "thinking", "speaking"})
# Detector misses shorter than this do not count as the person leaving Attentive.
ATTENTIVE_LOST_S = 1.0


@dataclass(frozen=True)
class ControllerConfig:
    dwell_s: float = 1.5
    depart_empty_s: float = 3.0
    greet_cooldown_s: float = 20.0
    silence_followup_s: float = 8.0
    max_followups: int = 1
    answer_timeout_s: float = 6.0
    farewell_silent_s: float = 2.0
    fps_idle: float = 8.0
    fps_engaged: float = 2.0
    kids_default: bool = False

    @classmethod
    def from_config(cls, cfg: dict) -> ControllerConfig:
        v, e = cfg["vision"], cfg["engagement"]
        return cls(
            dwell_s=v["dwell_s"],
            depart_empty_s=v["depart_empty_s"],
            greet_cooldown_s=e["greet_cooldown_s"],
            silence_followup_s=e["silence_followup_s"],
            max_followups=e["max_followups"],
            answer_timeout_s=cfg["llm"]["timeout_s"],
            farewell_silent_s=e["farewell_silent_s"],
            fps_idle=v["fps_idle"],
            fps_engaged=v["fps_engaged"],
            kids_default=e["kids_default"],
        )


class Controller:
    def __init__(self, cfg: ControllerConfig, phrases: Phrases = PHRASES) -> None:
        self.cfg = cfg
        self.p = phrases
        self.state = "idle"
        self.camera_ok = True
        self.count = 0
        self.approaching = False
        self.empty_since: float | None = 0.0
        self.cooldown_until = 0.0
        self._ids = itertools.count(1)
        self._reset_session()

    def _reset_session(self) -> None:
        self.kids = self.cfg.kids_default
        self.history: list[tuple[str, str]] = []
        self.pending: list[str] = []
        self.followups = 0
        self.listen_since: float | None = None
        self.attentive_since: float | None = None
        self.greeted_at: float | None = None
        self.conversation_started = False
        self.question: str | None = None
        self.reply: list[str] = []
        self.answer_done = False
        self.got_sentence = False
        self.ask_since: float | None = None
        self.farewell_until: float | None = None

    # ---- entry point ----

    def handle(self, event: Event, now: float) -> list[Command]:
        out: list[Command] = []
        match event:
            case Presence():
                self._on_presence(event, now, out)
            case SpeechFinal(text=text):
                self._on_speech_final(text, now, out)
            case SpeechEnded(id=sid):
                self._on_speech_ended(sid, now, out)
            case AnswerSentence(text=text):
                self._on_sentence(text, now, out)
            case AnswerDone():
                self._on_answer_done(now, out)
            case AnswerFailed(kind=kind):
                if self.state == "thinking":
                    self._fail(kind, now, out)
                elif self.state == "speaking":
                    self._on_answer_done(now, out)
            case Touch():
                self._on_touch(event, now, out)
            case CameraStatus(ok=ok):
                self.camera_ok = ok
                out.append(UiSend({"type": "camera", "ok": ok}))
            case Tick():
                pass
        self._on_timers(now, out)
        return out

    # ---- events ----

    def _on_presence(self, ev: Presence, now: float, out: list[Command]) -> None:
        self.count = ev.count
        self.approaching = ev.approaching
        if ev.count > 0:
            self.empty_since = None
            if self.state != "idle":
                out.append(UiSend({"type": "lookAt", "x": ev.cx, "y": ev.cy}))
        elif self.empty_since is None:
            self.empty_since = now

    def _on_speech_final(self, text: str, now: float, out: list[Command]) -> None:
        text = text.strip()
        if self.state != "listening" or self.pending or not text:
            return
        if is_decline(text):
            out.append(Record("decline"))
            self._farewell(now, out, spoken=True)
            return
        if not self.conversation_started:
            self.conversation_started = True
            out.append(Record("conversation_start"))
        out.append(Record("question"))
        self.question = text
        self.reply = []
        self.answer_done = False
        self.got_sentence = False
        self.ask_since = now
        self._enter("thinking", now, out)
        out.append(MicMute(True))
        out.append(Ask(text, tuple(self.history[-3:]), self.kids))

    def _on_speech_ended(self, sid: str, now: float, out: list[Command]) -> None:
        if sid not in self.pending:
            return
        del self.pending[: self.pending.index(sid) + 1]
        if self.pending:
            return
        if self.state == "greeting":
            self._enter("listening", now, out)
        elif self.state == "listening":
            out.append(MicMute(False))
            self.listen_since = now
        elif self.state == "speaking" and self.answer_done:
            self._end_turn(now, out)
        elif self.state == "farewell":
            self._finish(now, out)

    def _on_sentence(self, text: str, now: float, out: list[Command]) -> None:
        if self.state not in ("thinking", "speaking") or self.question is None:
            return
        if not self.got_sentence:
            self.got_sentence = True
            out.append(Record("reply_latency_ms", round((now - self.ask_since) * 1000)))
            self._enter("speaking", now, out)
        self.reply.append(text)
        self._speak(text, out, display=" ".join(self.reply))

    def _on_answer_done(self, now: float, out: list[Command]) -> None:
        if self.question is None:
            return
        if self.state == "thinking":
            self._fail("unmatched", now, out)
            return
        if self.state != "speaking":
            return
        self.answer_done = True
        out.append(Record("answered"))
        if not self.pending:
            self._end_turn(now, out)

    def _on_touch(self, t: Touch, now: float, out: list[Command]) -> None:
        s = self.state
        # A touch proves someone is at the screen, even if the camera has not seen them yet.
        if self.empty_since is not None:
            self.empty_since = now
        if t.event == "kids":
            self.kids = bool(t.value)
        elif t.event == "talk":
            if s == "idle":
                out.append(Record("encounter"))
                self._greet(now, out)
            elif s == "attentive":
                self._greet(now, out)
        elif t.event == "stop":
            if s in ("greeting", "thinking", "speaking"):
                self.pending.clear()
                self.question = None
                out += [StopSpeech(), CancelAnswer()]
                self._enter("listening", now, out)
        elif t.event == "menu_item":
            item = next((m for m in self.p.menu if m.id == t.value), None)
            if item is None or s == "farewell":
                return
            if s in ("idle", "attentive") and self.greeted_at is None:
                if s == "idle":
                    out.append(Record("encounter"))
                self.greeted_at = now
            out.append(Record("fallback"))
            if self.pending or s in ("thinking", "speaking"):
                self.pending.clear()
                out += [StopSpeech(), CancelAnswer()]
            self._answer_fixed(item.answer, now, out)

    # ---- timers ----

    def _on_timers(self, now: float, out: list[Command]) -> None:
        s, c = self.state, self.cfg
        present = self.count > 0
        empty_for = now - self.empty_since if self.empty_since is not None else 0.0
        if s == "idle":
            if present and self.camera_ok and now >= self.cooldown_until:
                self.attentive_since = now
                out.append(Record("encounter"))
                self._enter("attentive", now, out)
                if self.approaching:
                    self._greet(now, out)
        elif s == "attentive":
            if not present and empty_for >= ATTENTIVE_LOST_S:
                self._enter("idle", now, out)
            elif present and (self.approaching or now - self.attentive_since >= c.dwell_s):
                self._greet(now, out)
        elif s in ENGAGED:
            if self.camera_ok and not present and empty_for >= c.depart_empty_s:
                out.append(Record("walkaway"))
                self._farewell(now, out, spoken=False)
            elif s == "listening":
                self._listening_timer(now, out)
            elif (
                s == "thinking"
                and not self.got_sentence
                and now - self.ask_since >= c.answer_timeout_s
            ):
                out.append(CancelAnswer())
                self._fail("offline", now, out)
        elif s == "farewell":
            if self.farewell_until is not None and now >= self.farewell_until:
                self._finish(now, out)

    def _listening_timer(self, now: float, out: list[Command]) -> None:
        if self.pending or self.listen_since is None:
            return
        if now - self.listen_since < self.cfg.silence_followup_s:
            return
        if self.followups < self.cfg.max_followups:
            self.followups += 1
            self.listen_since = None
            self._speak(self.p.followup, out)
        elif not self.camera_ok:
            # Without a camera we cannot see them leave, so silence ends the encounter.
            self._farewell(now, out, spoken=True)
        else:
            self.listen_since = None

    # ---- actions ----

    def _enter(self, state: str, now: float, out: list[Command], text: str | None = None) -> None:
        prev, self.state = self.state, state
        msg = {"type": "state", "state": state}
        if text is not None:
            msg["text"] = text
        out.append(UiSend(msg))
        if state in ENGAGED and prev not in ENGAGED:
            out.append(VisionRate(self.cfg.fps_engaged))
        elif state == "idle" and (prev in ENGAGED or prev == "farewell"):
            out.append(VisionRate(self.cfg.fps_idle))
        if state == "listening":
            out.append(MicMute(False))
            self.listen_since = now

    def _speak(self, text: str, out: list[Command], display: str | None = None) -> None:
        sid = f"s{next(self._ids)}"
        self.pending.append(sid)
        out.append(MicMute(True))
        out.append(UiSend({"type": "say", "text": display if display is not None else text}))
        out.append(Speak(sid, text))

    def _greet(self, now: float, out: list[Command]) -> None:
        self.greeted_at = now
        out.append(Record("greeting"))
        self._enter("greeting", now, out)
        if self.count >= 2:
            text = self.p.group_greet
        elif self.kids:
            text = self.p.kids_greet
        else:
            text = self.p.greet
        self._speak(text, out)

    def _answer_fixed(self, text: str, now: float, out: list[Command]) -> None:
        """Speak a reply that does not come from the LLM, then return to listening."""
        self.question = None
        self.reply = []
        self.got_sentence = True
        self.answer_done = True
        self._enter("speaking", now, out)
        self._speak(text, out)

    def _fail(self, kind: str, now: float, out: list[Command]) -> None:
        out.append(Record("unmatched" if kind == "unmatched" else "fallback"))
        self._answer_fixed(self.p.unmatched if kind == "unmatched" else self.p.offline, now, out)
        items = [{"id": m.id, "label": m.label} for m in self.p.menu]
        out.append(UiSend({"type": "menu", "show": True, "items": items}))

    def _end_turn(self, now: float, out: list[Command]) -> None:
        if self.question is not None and self.reply:
            self.history.append((self.question, " ".join(self.reply)))
        self.question = None
        self._enter("listening", now, out)

    def _farewell(self, now: float, out: list[Command], spoken: bool) -> None:
        if self.pending or self.state in ("thinking", "speaking"):
            out += [StopSpeech(), CancelAnswer()]
        self.pending.clear()
        self.question = None
        self._enter("farewell", now, out)
        out.append(UiSend({"type": "menu", "show": False}))
        if spoken:
            self.farewell_until = None
            self._speak(self.p.bye, out)
        else:
            self.farewell_until = now + self.cfg.farewell_silent_s

    def _finish(self, now: float, out: list[Command]) -> None:
        if self.greeted_at is not None:
            out.append(Record("conversation_end", round(now - self.greeted_at, 1)))
        self._reset_session()
        self.cooldown_until = now + self.cfg.greet_cooldown_s
        self._enter("idle", now, out)
        out.append(UiSend({"type": "kids", "value": self.kids}))
```

```python
"""Speech output: the interface, an M1 stand-in, and the ordered playback queue."""

import asyncio
import base64
import logging
import random
from array import array
from collections.abc import AsyncIterator, Awaitable, Callable
from typing import Protocol

log = logging.getLogger("kiosk.speech")


class SpeechOutput(Protocol):
    sample_rate: int

    def synthesize(self, text: str) -> AsyncIterator[bytes]:
        """Yield little-endian PCM16 mono chunks."""


class FakeSpeech:
    """Speech-like babble so the mouth moves before Piper is wired in (replaced in M2)."""

    sample_rate = 22050

    def __init__(self, seconds_per_char: float = 0.055, chunk_s: float = 0.25) -> None:
        self.seconds_per_char = seconds_per_char
        self.chunk_s = chunk_s

    async def synthesize(self, text: str) -> AsyncIterator[bytes]:
        seconds = min(12.0, max(0.6, len(text) * self.seconds_per_char))
        pcm = _babble(seconds, self.sample_rate, random.Random(len(text)))
        step = int(self.chunk_s * self.sample_rate)
        for off in range(0, len(pcm), step):
            yield pcm[off : off + step].tobytes()
            await asyncio.sleep(0)


def _babble(seconds: float, rate: int, rnd: random.Random) -> array:
    """Sawtooth bursts shaped like syllables, with short and long pauses."""
    out = array("h")
    t = 0.0
    while t < seconds:
        syllable = 0.12 + rnd.random() * 0.12
        pause = 0.25 if rnd.random() < 0.18 else 0.03
        freq = 130 + rnd.random() * 60
        amp = 0.18 + rnd.random() * 0.12
        n = int(syllable * rate)
        for i in range(n):
            x = i / n
            env = x / 0.35 if x < 0.35 else (1 - x) / 0.65
            phase = (i * freq / rate) % 1.0
            out.append(int(32767 * amp * env * (2 * phase - 1)))
        out.extend([0] * int(pause * rate))
        t += syllable + pause
    return out


class SpeechQueue:
    """Synthesises one utterance at a time so sentences never interleave."""

    def __init__(
        self,
        speech: SpeechOutput,
        send: Callable[[dict], Awaitable[None]],
        on_failed: Callable[[str], Awaitable[None]],
    ) -> None:
        self.speech = speech
        self.send = send
        self.on_failed = on_failed
        self._q: asyncio.Queue[tuple[str, str]] = asyncio.Queue()
        self._current: asyncio.Task | None = None

    def put(self, sid: str, text: str) -> None:
        self._q.put_nowait((sid, text))

    def clear(self) -> None:
        while not self._q.empty():
            self._q.get_nowait()
        if self._current:
            self._current.cancel()

    async def run(self) -> None:
        while True:
            sid, text = await self._q.get()
            self._current = asyncio.create_task(self._speak(sid, text))
            await asyncio.wait({self._current})
            self._current = None

    async def _speak(self, sid: str, text: str) -> None:
        rate = self.speech.sample_rate
        try:
            async for pcm in self.speech.synthesize(text):
                await self.send(
                    {
                        "type": "audio",
                        "format": "pcm16",
                        "sampleRate": rate,
                        "data": base64.b64encode(pcm).decode("ascii"),
                        "id": sid,
                    }
                )
        except asyncio.CancelledError:
            raise
        except Exception:
            log.exception("speech synthesis failed")
            await self.on_failed(sid)
```

```python
class Answerer(Protocol):
    def answer(
        self, question: str, history: tuple[tuple[str, str], ...], kids: bool
    ) -> AsyncIterator[str]:
        """Yield spoken sentences; raise AnswerError when there is no answer."""


class CannedAnswerer:
    """Echoes the question. Set `offline` to exercise the fallback menu."""

    def __init__(self, delay_s: float = 0.8) -> None:
        self.delay_s = delay_s
        self.offline = False

    async def answer(
        self, question: str, history: tuple[tuple[str, str], ...], kids: bool
    ) -> AsyncIterator[str]:
        await asyncio.sleep(self.delay_s)
        if self.offline:
            raise AnswerError("offline")
        yield f"You asked: {question.strip().rstrip('?.!')}."
        await asyncio.sleep(self.delay_s / 2)
        yield "Real answers from the knowledge base arrive in the next milestone."
```

```python
"""Runs the controller: feeds it events and carries out the commands it returns."""

import asyncio
import logging
import time
from collections.abc import Awaitable, Callable

from core import __version__
from core.answer import Answerer, AnswerError
from core.controller.machine import Controller
from core.controller.types import (
    AnswerDone,
    AnswerFailed,
    AnswerSentence,
    Ask,
    CameraStatus,
    CancelAnswer,
    Event,
    MicMute,
    Presence,
    Record,
    Speak,
    SpeechEnded,
    SpeechFinal,
    StopSpeech,
    Tick,
    Touch,
    UiSend,
    VisionRate,
)
from core.speech import SpeechOutput, SpeechQueue

log = logging.getLogger("kiosk.core")

TICK_S = 0.1
TOUCH_EVENTS = ("talk", "stop", "kids", "menu_item")


class Runtime:
    def __init__(
        self,
        controller: Controller,
        speech: SpeechOutput,
        answerer: Answerer,
        send: Callable[[dict], Awaitable[None]],
        *,
        dev: bool = False,
        music: dict | None = None,
        clock: Callable[[], float] = time.monotonic,
        record: Callable[[str, float | None], None] | None = None,
    ) -> None:
        self.c = controller
        self.answerer = answerer
        self.send = send
        self.dev = dev
        self.music = music
        self.clock = clock
        self.record = record or (lambda kind, value: log.info("event %s %s", kind, value))
        self.mic_muted = True
        self.vision_fps: float | None = None
        self.voice = SpeechQueue(speech, send, self._speech_failed)
        self._lock = asyncio.Lock()
        self._answer_task: asyncio.Task | None = None
        self._tasks: set[asyncio.Task] = set()

    # ---- lifecycle ----

    def start(self) -> None:
        self._spawn(self._tick_loop())
        self._spawn(self.voice.run())

    async def stop(self) -> None:
        self._cancel_answer()
        for task in self._tasks:
            task.cancel()
        await asyncio.gather(*self._tasks, return_exceptions=True)
        self._tasks.clear()

    def snapshot(self) -> list[dict]:
        """Messages a newly connected UI needs; the current state goes last."""
        msgs = [
            {"type": "version", "version": __version__},
            {"type": "dev", "enabled": self.dev},
            {"type": "camera", "ok": self.c.camera_ok},
        ]
        if self.music:
            msgs.append({"type": "music", **self.music})
        msgs.append({"type": "state", "state": self.c.state})
        return msgs

    # ---- events in ----

    async def handle(self, event: Event) -> None:
        async with self._lock:
            commands = self.c.handle(event, self.clock())
            await self._run(commands)

    async def on_ui(self, msg: dict) -> None:
        kind = msg.get("type")
        if kind == "speech.ended":
            await self.handle(SpeechEnded(str(msg.get("id"))))
        elif kind == "ui" and msg.get("event") in TOUCH_EVENTS:
            await self.handle(Touch(msg["event"], msg.get("value")))
        elif kind == "dev" and self.dev:
            await self._dev(msg)

    async def _dev(self, msg: dict) -> None:
        action = msg.get("action")
        if action == "approach":
            await self.handle(Presence(1, approaching=True))
        elif action == "group":
            await self.handle(Presence(2, approaching=True))
        elif action == "linger":
            await self.handle(Presence(1))
        elif action == "walkpast":
            await self.handle(Presence(1, cx=-0.8))
            self._spawn(self._later(1.0, Presence(0)))
        elif action == "leave":
            await self.handle(Presence(0))
        elif action == "ask":
            text = str(msg.get("text", "")).strip()
            if text:
                await self.handle(SpeechFinal(text))
        elif action == "camera":
            await self.handle(CameraStatus(bool(msg.get("ok"))))
        elif action == "internet" and hasattr(self.answerer, "offline"):
            self.answerer.offline = not bool(msg.get("ok"))

    # ---- commands out ----

    async def _run(self, commands: list) -> None:
        for cmd in commands:
            match cmd:
                case UiSend(msg=msg):
                    await self.send(msg)
                case Speak(id=sid, text=text):
                    self.voice.put(sid, text)
                case StopSpeech():
                    self.voice.clear()
                    await self.send({"type": "stopAudio"})
                case MicMute(muted=muted):
                    self.mic_muted = muted
                case VisionRate(fps=fps):
                    self.vision_fps = fps
                case Ask():
                    self._cancel_answer()
                    self._answer_task = self._spawn(self._answer(cmd))
                case CancelAnswer():
                    self._cancel_answer()
                case Record(type=kind, value=value):
                    self.record(kind, value)

    async def _answer(self, ask: Ask) -> None:
        try:
            async for sentence in self.answerer.answer(ask.question, ask.history, ask.kids):
                await self.handle(AnswerSentence(sentence))
            await self.handle(AnswerDone())
        except AnswerError as e:
            await self.handle(AnswerFailed(e.kind))
        except Exception:
            log.exception("answer failed")
            await self.handle(AnswerFailed("offline"))

    async def _speech_failed(self, sid: str) -> None:
        # Treat a failed utterance as played so the conversation moves on.
        await self.handle(SpeechEnded(sid))

    # ---- helpers ----

    def _cancel_answer(self) -> None:
        task = self._answer_task
        if task and not task.done() and task is not asyncio.current_task():
            task.cancel()
        self._answer_task = None

    async def _tick_loop(self) -> None:
        while True:
            await self.handle(Tick())
            await asyncio.sleep(TICK_S)

    async def _later(self, delay: float, event: Event) -> None:
        await asyncio.sleep(delay)
        await self.handle(event)

    def _spawn(self, coro) -> asyncio.Task:
        task = asyncio.create_task(coro)
        self._tasks.add(task)
        task.add_done_callback(self._tasks.discard)
        return task
```

```python
"""FastAPI app for the kiosk screen: character UI, its WebSocket, and /health.

The staff dashboard API on port 8080 is added in M5.
"""

import json
from contextlib import asynccontextmanager
from pathlib import Path

from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.staticfiles import StaticFiles

from core.answer import CannedAnswerer
from core.controller.machine import Controller, ControllerConfig
from core.runtime import Runtime
from core.speech import FakeSpeech

UI_DIR = Path(__file__).resolve().parents[1] / "ui"


class Hub:
    """Every connected UI page; messages go to all of them."""

    def __init__(self) -> None:
        self._clients: set[WebSocket] = set()

    def add(self, ws: WebSocket) -> None:
        self._clients.add(ws)

    def remove(self, ws: WebSocket) -> None:
        self._clients.discard(ws)

    async def broadcast(self, msg: dict) -> None:
        for ws in list(self._clients):
            try:
                await ws.send_json(msg)
            except Exception:
                self._clients.discard(ws)


def create_app(cfg: dict, dev: bool = False) -> FastAPI:
    hub = Hub()
    music_url = cfg["ui"].get("music_url")
    music = {"url": music_url, "volume": cfg["audio"]["music_volume"]} if music_url else None
    runtime = Runtime(
        Controller(ControllerConfig.from_config(cfg)),
        FakeSpeech(),
        CannedAnswerer(),
        hub.broadcast,
        dev=dev,
        music=music,
    )

    @asynccontextmanager
    async def lifespan(_app: FastAPI):
        runtime.start()
        yield
        await runtime.stop()

    app = FastAPI(lifespan=lifespan)
    app.state.runtime = runtime

    @app.get("/health")
    async def health() -> dict:
        return {"ok": True}

    @app.websocket("/ws")
    async def ws_endpoint(sock: WebSocket) -> None:
        await sock.accept()
        try:
            for msg in runtime.snapshot():
                await sock.send_json(msg)
            hub.add(sock)
            while True:
                raw = await sock.receive_text()
                try:
                    msg = json.loads(raw)
                except ValueError:
                    continue
                if isinstance(msg, dict):
                    await runtime.on_ui(msg)
        except WebSocketDisconnect:
            pass
        finally:
            hub.remove(sock)

    app.mount("/", StaticFiles(directory=UI_DIR, html=True), name="ui")
    return app
```

```js
// Speech goes through the analyser (it drives the mouth). Music has its own gain path,
// so it never moves the mouth (baseline 4.4).
export class AudioEngine {
  constructor() {
    this.ctx = null;
    this.analyser = null;
    this.buf = null;
    this.nextTime = 0;
    this.live = new Set();
    this.lastId = null;
    this.onDrained = () => {};
    this.musicEl = null;
    this.musicGain = null;
    this.musicBase = 0.25;
  }

  ensure() {
    if (!this.ctx) {
      this.ctx = new AudioContext();
      this.analyser = this.ctx.createAnalyser();
      this.analyser.fftSize = 1024;
      this.analyser.connect(this.ctx.destination);
      this.buf = new Float32Array(this.analyser.fftSize);
    }
    if (this.ctx.state === 'suspended') this.ctx.resume();
    return this.ctx;
  }

  // Queue one base64 PCM16 mono chunk right after the previous one.
  playPCM16(base64, sampleRate, id) {
    const ctx = this.ensure();
    const bin = atob(base64);
    const n = bin.length >> 1;
    const samples = new Float32Array(n);
    for (let i = 0; i < n; i++) {
      let v = bin.charCodeAt(2 * i) | (bin.charCodeAt(2 * i + 1) << 8);
      if (v >= 0x8000) v -= 0x10000;
      samples[i] = v / 32768;
    }
    const buffer = ctx.createBuffer(1, n, sampleRate);
    buffer.copyToChannel(samples, 0);
    const src = ctx.createBufferSource();
    src.buffer = buffer;
    src.connect(this.analyser);
    this.nextTime = Math.max(this.nextTime, ctx.currentTime + 0.05);
    src.start(this.nextTime);
    this.nextTime += buffer.duration;
    if (id !== undefined) this.lastId = id;
    this.live.add(src);
    src.onended = () => {
      this.live.delete(src);
      if (this.live.size === 0) {
        this.nextTime = 0;
        this.onDrained(this.lastId);
      }
    };
  }

  stop() {
    for (const src of this.live) {
      src.onended = null;
      try { src.stop(); } catch { /* already stopped */ }
    }
    this.live.clear();
    this.nextTime = 0;
  }

  // Speech loudness 0..1 for the mouth.
  level() {
    if (!this.analyser || this.live.size === 0) return 0;
    this.analyser.getFloatTimeDomainData(this.buf);
    let sum = 0;
    for (const v of this.buf) sum += v * v;
    const rms = Math.sqrt(sum / this.buf.length);
    return Math.min(1, Math.max(0, (rms - 0.012) * 7));
  }

  setMusic(url, volume = this.musicBase) {
    const ctx = this.ensure();
    this.musicBase = volume;
    if (this.musicEl) this.musicEl.pause();
    this.musicEl = null;
    if (!url) return;
    if (!this.musicGain) {
      this.musicGain = ctx.createGain();
      this.musicGain.connect(ctx.destination);
    }
    this.musicEl = new Audio(url);
    this.musicEl.loop = true;
    ctx.createMediaElementSource(this.musicEl).connect(this.musicGain);
    this.musicGain.gain.value = this.musicBase;
    this.musicEl.play().catch(() => {});
  }

  // Full volume in Idle, 35% when someone is in the zone, silent while talking or listening.
  duckFor(state) {
    if (!this.musicGain) return;
    const target = state === 'idle' ? this.musicBase : state === 'attentive' ? this.musicBase * 0.35 : 0;
    const secs = state === 'idle' ? 2.5 : state === 'attentive' ? 0.6 : 0.3;
    const gain = this.musicGain.gain;
    const now = this.ctx.currentTime;
    gain.cancelScheduledValues(now);
    gain.setValueAtTime(gain.value, now);
    gain.linearRampToValueAtTime(target, now + secs);
  }
}
```

```js
// Per-frame character animation: the mouth light bar follows speech loudness,
// the eyes blink and follow the visitor. CSS handles everything else.
const clamp = (v) => Math.max(-1, Math.min(1, Number(v) || 0));

export function startBot(root, audio) {
  const mouth = root.querySelector('#mouth');
  const eyes = root.querySelector('#eyes');
  const eyeL = root.querySelector('#eyeL');
  const eyeR = root.querySelector('#eyeR');
  const meter = root.querySelector('#devMeter');
  let level = 0;
  let blink = 1;
  let nextBlink = performance.now() + 2500;
  const look = { x: 0, y: 0 };
  let target = { x: 0, y: 0 };

  function frame(now) {
    // Fast attack, slower release reads as natural speech.
    const want = audio.level();
    level += (want - level) * (want > level ? 0.55 : 0.22);
    const w = 20 + level * 56;
    const h = 4 + level * 6;
    mouth.setAttribute('x', (200 - w / 2).toFixed(1));
    mouth.setAttribute('width', w.toFixed(1));
    mouth.setAttribute('y', (206 - h / 2).toFixed(1));
    mouth.setAttribute('height', h.toFixed(1));
    mouth.setAttribute('opacity', (level > 0.02 ? 0.35 + level * 0.65 : 0).toFixed(2));
    if (meter) meter.style.width = `${Math.round(level * 100)}%`;

    if (now > nextBlink) {
      blink = 0.08;
      nextBlink = now + 2200 + Math.random() * 3500;
    }
    blink += (1 - blink) * 0.25;

    const state = root.dataset.state;
    const goal = state === 'thinking' ? { x: 0.5, y: -0.7 } : state === 'idle' ? { x: 0, y: 0 } : target;
    look.x += (goal.x - look.x) * 0.08;
    look.y += (goal.y - look.y) * 0.08;
    eyes.setAttribute('transform', `translate(${(look.x * 14).toFixed(1)} ${(look.y * 8).toFixed(1)})`);
    const ry = 13 * blink * (state === 'listening' ? 1.15 : 1);
    eyeL.setAttribute('ry', ry.toFixed(1));
    eyeR.setAttribute('ry', ry.toFixed(1));
    requestAnimationFrame(frame);
  }
  requestAnimationFrame(frame);

  return {
    lookAt(x, y = 0) {
      target = { x: clamp(x), y: clamp(y) };
    },
  };
}
```

```js
// WebSocket link to kiosk-core on the same host. Reconnects every 2 s.
export function connectBridge(onMessage) {
  let ws = null;
  const url = `${location.protocol === 'https:' ? 'wss' : 'ws'}://${location.host}/ws`;

  function open() {
    ws = new WebSocket(url);
    ws.onmessage = (ev) => {
      let msg;
      try { msg = JSON.parse(ev.data); } catch { return; }
      onMessage(msg);
    };
    ws.onclose = () => {
      ws = null;
      setTimeout(open, 2000);
    };
    ws.onerror = () => {};
  }
  open();

  return {
    send(obj) {
      if (ws && ws.readyState === WebSocket.OPEN) ws.send(JSON.stringify(obj));
    },
  };
}
```

```js
      const span = document.createElement('span');
      span.className = 'prompt';
      span.textContent = t('prompt');
      el.append(span);
    } else if (item.journey) {
      const row = document.createElement('div');
      row.className = 'journey';
      t('journey').forEach((word, k) => {
        if (k) {
          const arrow = document.createElement('em');
          arrow.textContent = '→';
          row.append(arrow);
        }
        const step = document.createElement('span');
        step.textContent = word;
        row.append(step);
      });
      el.append(row);
      const steps = row.querySelectorAll('span');
      let k = 0;
      steps[0].classList.add('on');
      stepTimer = setInterval(() => {
        k = Math.min(k + 1, steps.length - 1);
        steps[k].classList.add('on');
      }, 1200);
    } else {
      el.textContent = item.text;
    }
  }

  render();
  setInterval(() => {
    el.classList.add('fade');
    setTimeout(() => {
      i++;
      render();
      el.classList.remove('fade');
    }, 500);
  }, 6500);
}

// "Tap to talk" turns into "Stop" while the bot is talking or thinking.
export function bindTalk(btn, label, root, send) {
  const busy = () => ['greeting', 'thinking', 'speaking'].includes(root.dataset.state);
  btn.addEventListener('click', () => send({ type: 'ui', event: busy() ? 'stop' : 'talk' }));
  return function refresh() {
    label.textContent = busy() ? t('stop') : t('talk');
  };
}

export function bindKids(btn, send) {
  btn.textContent = t('kids');
  btn.addEventListener('click', () => {
    const on = btn.getAttribute('aria-pressed') !== 'true';
    btn.setAttribute('aria-pressed', String(on));
    send({ type: 'ui', event: 'kids', value: on });
  });
  return {
    set(on) {
      btn.setAttribute('aria-pressed', String(Boolean(on)));
    },
  };
}

// Opens only after a continuous press, so visitors do not open it by accident.
export function bindGear(btn, holdSeconds, onOpen) {
  let timer = null;
  btn.style.setProperty('--hold', `${holdSeconds}s`);
  const cancel = () => {
    clearTimeout(timer);
    timer = null;
    btn.classList.remove('holding');
  };
  btn.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    btn.setPointerCapture(e.pointerId);
    btn.classList.add('holding');
    timer = setTimeout(() => {
      cancel();
      onOpen();
    }, holdSeconds * 1000);
  });
  for (const type of ['pointerup', 'pointercancel', 'lostpointercapture']) btn.addEventListener(type, cancel);
  btn.addEventListener('contextmenu', (e) => e.preventDefault());
}

export function bindSheet(sheet, send) {
  const grid = sheet.querySelector('#menuItems');
  const close = sheet.querySelector('#sheetClose');
  sheet.querySelector('#sheetTitle').textContent = t('menuTitle');
  close.textContent = t('menuClose');
  const hide = () => {
    sheet.classList.remove('open');
    sheet.setAttribute('aria-hidden', 'true');
  };
  close.addEventListener('click', hide);
  return {
    show(items) {
      grid.replaceChildren(
        ...items.map((item) => {
          const b = document.createElement('button');
          b.type = 'button';
          b.textContent = item.label;
          b.addEventListener('click', () => {
            hide();
            send({ type: 'ui', event: 'menu_item', value: item.id });
          });
          return b;
        }),
      );
      sheet.classList.add('open');
      sheet.setAttribute('aria-hidden', 'false');
    },
    hide,
  };
}
```

```js
// Dev panel: fake visitors, typed questions, forced faults. Core ignores these
// messages unless it runs with --dev. "Preview state" only changes this page.
const STATES = ['idle', 'attentive', 'greeting', 'listening', 'thinking', 'speaking', 'farewell'];

export function bindDev(panel, root, send) {
  let enabled = new URLSearchParams(location.search).has('dev');

  for (const b of panel.querySelectorAll('[data-dev]')) {
    b.addEventListener('click', () => {
      const action = b.dataset.dev;
      if (action === 'camera' || action === 'internet') {
        const ok = b.dataset.ok === 'true';
        send({ type: 'dev', action, ok });
        b.dataset.ok = String(!ok);
        b.textContent = `${action === 'camera' ? 'Camera' : 'Internet'} ${ok ? 'fail' : 'restore'}`;
        return;
      }
      send({ type: 'dev', action });
    });
  }

  panel.querySelector('#devAsk').addEventListener('submit', (e) => {
    e.preventDefault();
    const input = panel.querySelector('#devQuestion');
    const text = input.value.trim();
    if (!text) return;
    send({ type: 'dev', action: 'ask', text });
    input.value = '';
  });

  const row = panel.querySelector('#devStates');
  for (const s of STATES) {
    const b = document.createElement('button');
    b.type = 'button';
    b.textContent = s;
    b.addEventListener('click', () => { root.dataset.state = s; });
    row.append(b);
  }

  addEventListener('keydown', (e) => {
    if (enabled && (e.key === 'd' || e.key === 'D') && e.target.tagName !== 'INPUT') panel.hidden = !panel.hidden;
  });

  return {
    show(on) {
      enabled = enabled || Boolean(on);
      panel.hidden = !enabled;
    },
  };
}
```

```js
import { t } from './strings.js';
import { AudioEngine } from './audio.js';
import { startBot } from './bot.js';
import { connectBridge } from './bridge.js';
import { startTicker, bindTalk, bindKids, bindGear, bindSheet } from './controls.js';
import { bindDev } from './dev.js';

// The staff dashboard (M5) is served by kiosk-core on port 8080.
const ADMIN_URL = 'http://localhost:8080/';
const GEAR_HOLD_S = 3;

const root = document.getElementById('root');
const bubble = document.getElementById('bubble');
const privacy = document.getElementById('privacyText');

const audio = new AudioEngine();
const bot = startBot(root, audio);
const bridge = connectBridge(handle);
const send = (msg) => bridge.send(msg);
audio.onDrained = (id) => send({ type: 'speech.ended', id });

const refreshTalk = bindTalk(document.getElementById('talk'), document.getElementById('talkLabel'), root, send);
const kids = bindKids(document.getElementById('kids'), send);
const sheet = bindSheet(document.getElementById('sheet'), send);
const dev = bindDev(document.getElementById('dev'), root, send);
bindGear(document.getElementById('gear'), GEAR_HOLD_S, () => { location.href = ADMIN_URL; });
startTicker(document.getElementById('ticker'));
updatePrivacy();
refreshTalk();

let loadedVersion = null;

function say(text, partial = false) {
  if (!text) {
    bubble.classList.add('hide');
    return;
  }
  bubble.textContent = text;
  bubble.classList.toggle('partial', partial);
  bubble.classList.remove('hide');
}

function setState(state, text) {
  root.dataset.state = state;
  if (text !== undefined) say(text);
  else if (state === 'listening') say(t('listening'));
  else if (['idle', 'attentive', 'thinking', 'farewell'].includes(state)) say(null);
  if (state === 'idle') sheet.hide();
  audio.duckFor(state);
  refreshTalk();
}

function updatePrivacy() {
  privacy.textContent = root.dataset.camera === 'off' ? t('privacyOff') : t('privacy');
}

function handle(m) {
  switch (m.type) {
    case 'state': setState(m.state, m.text); break;
    case 'say': say(m.text); break;
    case 'stt': say(m.text, !m.final); break;
    case 'lookAt': bot.lookAt(m.x, m.y); break;
    case 'audio': audio.playPCM16(m.data, m.sampleRate || 22050, m.id); break;
    case 'stopAudio': audio.stop(); break;
    case 'camera': root.dataset.camera = m.ok ? 'on' : 'off'; updatePrivacy(); break;
    case 'music': audio.setMusic(m.url, m.volume); break;
    case 'menu': if (m.show) sheet.show(m.items || []); else sheet.hide(); break;
    case 'kids': kids.set(m.value); break;
    case 'dev': dev.show(m.enabled); break;
    case 'version':
      if (loadedVersion && loadedVersion !== m.version) location.reload();
      loadedVersion = m.version;
      break;
  }
}

// On the kiosk, Chromium runs with --autoplay-policy=no-user-gesture-required.
// On a laptop, the first touch unlocks audio.
addEventListener('pointerdown', () => audio.ensure(), { once: true });

window.kiosk = { setState, say, lookAt: bot.lookAt, audio, get state() { return root.dataset.state; } };
```
